# Stakeholder Relationship Visualiser — Iberdrola

Interactive force-directed graph of Iberdrola's stakeholder relationships, built for the ApexSignal technical assignment.

See **DOCUMENTATION.md** for the data model, technical approach, legibility decisions, and scope notes.

## Quick start

```bash
npm install
npm run dev
```

## Deploy

```bash
npm install -g vercel
vercel --prod
```
